# Дипломы и сертификаты

Помещайте сюда только реальные документы, переданные Диной и разрешённые к публикации. Перед публикацией скройте номера и личные данные, которые не нужны посетителям. После загрузки замените placeholders в разделе «Образование и подготовка» на изображения и подписи, точно сверенные с оригиналами.

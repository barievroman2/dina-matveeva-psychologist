# Дина Матвеева — психолог

Статический сайт на HTML, CSS и JavaScript без сборки и обязательных сторонних библиотек.

## GitHub Pages
В репозитории откройте **Settings → Pages**, выберите **GitHub Actions** как Source, если workflow находится в `.github/workflows/pages.yml`. После успешного workflow сайт ожидается по адресу:
https://barievroman2.github.io/dina-matveeva-psychologist/

## Структура
- `index.html` — главная страница.
- `styles.css` — адаптивный кинематографичный дизайн.
- `script.js` — мобильная навигация и год в подвале.
- `assets/dina-matveeva-portrait.jpg` — фото-заглушка будет заменена оригинальным портретом в отдельном шаге.
- `assets/certificates/` — место для проверенных дипломов и сертификатов.
- `assets/products/` — обложки продуктов.
- `assets/products/pdf/` — зарезервировано; не помещайте сюда платный PDF, пока файл будет публично доступен.
- `data/products.json` — карточка-запись будущего продукта.

## Перед публичным продвижением
1. Поместить в `assets/dina-matveeva-portrait.jpg` реальный портрет Дины.
2. Добавить настоящие сертификаты и сверить названия программ.
3. Создать и проверить PDF. До этого продукт отмечен как «В разработке», оплата не реализована.
4. Согласовать текст сайта с Диной.
5. Подготовить необходимые юридические тексты.
6. Проверить сайт из российских сетей: доступность GitHub Pages без VPN не гарантируется.
